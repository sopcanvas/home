# SOP Canvas | Premium Academic Strategy

A professional landing page for high-stakes academic writing services, specializing in Statement of Purpose (SOP) and Visa documentation.

## ✨ Key Features
- **Modern Dark UI:** High-contrast luminescence palette (Charcoal & Emerald).
- **Fully Responsive:** Optimized for Mobile, Tablet, and Desktop.
- **Glassmorphism Design:** Subtle transparency and blur effects.
- **Smooth Animations:** Integrated with AOS (Animate On Scroll).
- **One-Click CTA:** Direct WhatsApp integration for consulting.

## 🚀 Deployment
This site is ready for **GitHub Pages**. To host it:
1. Create a repository on GitHub.
2. Upload `index.html`.
3. Enable "GitHub Pages" in the repository settings under the "Pages" tab.

## 🛠️ Built With
- HTML5 & CSS3
- Google Fonts (Plus Jakarta Sans)
- FontAwesome 6.4
- AOS Library (Animations)
